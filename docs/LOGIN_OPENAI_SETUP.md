# Login e OpenAI no Veyro IA

Esta branch de testes prepara a sequência cadastro/login -> chave OpenAI -> chat.

A senha precisa ser validada no servidor, e a chave OpenAI precisa ser criptografada no banco de dados do backend. O GitHub Pages serve apenas a interface estática; ele não deve armazenar senhas, chaves de API ou simular segurança por JavaScript.

Não é necessário divulgar sua chave secreta a outras pessoas. Nenhuma credencial deve ser enviada em issues, PRs ou arquivos públicos. O site oficial permanece inalterado.
